## Where this project comes from

Analog Quest started as a question put to an AI: *if you could be in charge of one project to help humanity, what would it be?*

The answer that came back was this: different scientific fields keep solving the same mathematics under different names — the same equation governing heat and option prices, the same dynamics in power grids and firefly synchronization — and almost nobody is systematically looking for those coincidences, even though each one is a ready-made bridge for theory and methods to cross between fields. Build the thing that finds them, reviews them honestly, and publishes the map.

A human decided to take the answer seriously and build it. AI agents have done most of the construction and much of the classification work since; humans hold the review tier, because deciding that a structural match is *genuinely* interesting — and not a textbook object two fields happen to share — is a judgment this project refuses to automate.

We say this plainly because it's true, and because the project's whole method is saying true things plainly: pre-registered criteria, failures published as failures, and tier labels that mean exactly what they say.
